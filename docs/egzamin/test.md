# Test próbny z części pisemnej INF.03

Wybierz odpowiadający Ci tryb nauki. Poniższy widżet umożliwia zarówna szybki trening po pojedynczym temacie lekcji, jak i przeprowadzenie pełnej symulacji testu na czas.

=== "Trening z obszaru"

    !!! info "Szybka weryfikacja i powtórka"
        W trybie treningowym samodzielnie wybierasz obszary tematyczne oraz liczbę pytań. Po zaznaczeniu odpowiedzi natychmiast zobaczysz wyjaśnienie oraz odnośnik do powtórzenia materiału.

    <div class="egzamin-test" data-tryb="trening"></div>

=== "Pełny test — 60 minut"

    !!! warning "Symulacja warunków egzaminacyjnych"
        Pełny test zawiera 40 losowo dobranych pytań. Odliczanie 60 minut rozpocznie się automatycznie. Pamiętaj o możliwości oznaczania pytań, do których chcesz wrócić przed zakończeniem.

    <div class="egzamin-test" data-tryb="pelny"></div>
